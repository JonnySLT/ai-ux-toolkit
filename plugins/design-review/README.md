# design-review

- **design-review** — run a structured design critique against the brief and codebase: visual hierarchy, consistency, responsiveness, accessibility, and aesthetic fidelity. A polish/QA pass after building.

> Complements this toolkit's `accessibility-heuristics` plugin: `design-review` is a broad, holistic critique (with accessibility as one lens); `accessibility-check` and `heuristic-review` are dedicated, deeper, standardised audits (WCAG success criteria; Nielsen's 10 heuristics). They stack well.
