# synthesis-artifacts

The bridge from research to design — turns synthesized insight into the artifacts that steer product decisions.

- **personas** — evidence-based personas and Jobs-to-be-Done statements grounded in real research (not invented demographics).
- **empathy-map** — a fast Says / Thinks / Does / Feels (+ Pains & Gains) snapshot of a user, grounded in evidence, that surfaces contradictions and design implications.
- **journey-map** — journey and experience maps: stages, actions, thoughts, emotions, pain points, and opportunities across an end-to-end experience.
- **service-blueprint** — extend a journey with the behind-the-scenes layers (frontstage, backstage, support processes/systems) to reveal fail points, handoffs, and ownership gaps.
- **success-metrics** — define what success looks like *before* you build, using HEART and the goal → signal → metric method, with guardrail metrics.

**Project-agnostic:** each skill works from your own research and product context. They pair with the `ux-research` plugin's `research-synthesis` (which produces the themes these artifacts are built from) and feed the `design-planning` brief.

No external services required. Triggers from natural language ("create personas", "map the user journey", "what metrics should we track for this?").

Install: `/plugin install synthesis-artifacts@ai-ux-toolkit`
