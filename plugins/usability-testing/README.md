# usability-testing

- **usability-testing** — the end-to-end usability study: a test plan (objectives, tasks with success criteria, metrics), moderation guidance, and a findings report with task-level success/error/ease data and severity-rated issues.

This is the **empirical, with-real-users** counterpart to the expert audits in `accessibility-heuristics` (`accessibility-check`, `heuristic-review`) and `design-review`. It's usability-method-specific — it complements, and cross-references, the more general `research-planning` (question craft) and `ux-research` → `research-synthesis` (qualitative coding).

**Project-agnostic:** works for any product, prototype, or live flow. No external services required. Triggers from natural language ("plan a usability test", "analyze my usability test results", "what tasks should I test?", "severity-rate these usability issues").

Install: `/plugin install usability-testing@ai-ux-toolkit`
