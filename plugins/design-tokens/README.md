# design-tokens

- **design-tokens** — generate a design tokens file (CSS variables or Tailwind config) from a chosen aesthetic philosophy: light and dark palettes, spacing scale, type ramp, and component-level tokens. Run after the brief, before building components.

Complements this toolkit's `handoff-docs` → `design-system-docs`, which runs in the opposite direction (documenting tokens that *already* exist).
