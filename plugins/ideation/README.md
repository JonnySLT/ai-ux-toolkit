# ideation

- **divergent-exploration** — generate a broad spread of options — product concepts, copy variants, or IA/layout structures — spanning safe → bold, each with a one-line rationale, so you break fixation early and edit rather than start blank.
- **facilitation** — plan and run collaborative sessions (kickoffs, design sprints, ideation workshops, prioritisation, retros): a timed agenda, the right activities for the goal, facilitation scripts, and how to capture outcomes.

**Project-agnostic:** works for any problem in any domain. Reads the project's design system, brand voice, or constraints if they exist, but needs none of them to run. The point is genuine variety — different underlying strategies, not reworded twins.

No external services required. Triggers from natural language ("give me 10 concepts for…", "some variants of this CTA", "different ways to structure this nav").

Install: `/plugin install ideation@ai-ux-toolkit`
