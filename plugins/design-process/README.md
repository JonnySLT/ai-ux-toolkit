# design-process

The end-to-end product-design workflow. `design-flow` orchestrates the other skills, so they're bundled together.

- **design-flow** — run the full design-to-build sequence.
- **design-brief** — interactive brief via interview + codebase exploration.
- **information-architecture** — navigation, hierarchy, page structure, user flows.
- **competitive-analysis** — live teardown of 3–6 products with a comparison matrix.
- **frontend-design** — build distinctive, production-grade frontend UI.
- **design-review** — structured critique against the brief (hierarchy, consistency, a11y, fidelity).
- **brief-to-tasks** — turn a brief into an ordered, buildable task checklist.

No external services required. Triggers from natural language ("write a design brief", "review this design", etc.).

Install: `/plugin install design-process@design-system-toolkit`
