# rapid-prototyping

- **rapid-prototype** — turn a rough idea, brief, sketch, or a set of chosen concepts into a clickable, functional prototype: minimal runnable front-end code (single-file HTML or React), verified live in the browser preview so you can test real interaction instead of static comps.

**Project-agnostic:** if the project has a design system or design tokens, the prototype uses them; otherwise it falls back to clean neutral defaults. Code-first by default (fast to run and test); can optionally scaffold in Figma instead.

**Requires** a browser preview the skill can drive (built into this environment). Triggers from natural language ("prototype this", "make a clickable version", "turn this into something I can click through").

Install: `/plugin install rapid-prototyping@ai-ux-toolkit`
