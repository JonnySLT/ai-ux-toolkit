# competitive-analysis

- **competitive-analysis** — run a live competitive teardown of 3–6 products. Browses each in real time and analyses UI patterns, messaging, features, and brand identity, then delivers a comparison matrix, a written narrative, and an opportunities/gaps list. Can optionally push findings into a Figma doc page.

Triggers from natural language ("research these competitors", "run a comp analysis", "benchmark this product"). Browsing requires a browser/MCP the skill can drive; pushing to Figma requires the Figma MCP.

Install: `/plugin install competitive-analysis@design-system-toolkit`
