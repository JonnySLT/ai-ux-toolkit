# information-architecture

- **information-architecture** — define the structural layer of a product or site before visual design begins: navigation, content hierarchy, page structure, URL patterns, and user flows.

Sits between the design brief and the build. Pairs with the `ideation` plugin's `divergent-exploration` (which can generate *options* for structure) — this skill commits to and details one.
