# design-planning

- **design-brief** — create a design brief through an interactive interview, codebase exploration, and experience-design decisions; saved as markdown.
- **grill-me** — interview you relentlessly about a plan or design until you reach shared understanding, resolving each branch of the decision tree.
- **brief-to-tasks** — break a design brief into an ordered checklist of independently buildable tasks (vertical slices).
- **design-flow** — the full design-to-build orchestrator: runs the whole sequence from grilling through review.

> `design-flow` orchestrates the other design skills by name — for the full sequence, also install the companion vendored plugins: `information-architecture`, `design-tokens`, `frontend-design`, and `design-review`.
