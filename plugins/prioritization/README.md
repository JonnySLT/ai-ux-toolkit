# prioritization

- **prioritization** — take a messy list of ideas, features, or fixes and turn it into a defensible ranked order. Picks the framework that fits the decision (RICE, impact/effort, MoSCoW, value-vs-complexity, Kano), scores each item transparently, and surfaces the quick wins and the assumptions the ranking rests on.

**Project-agnostic.** Works on the output of `ideation` → `divergent-exploration`, research opportunities from `research-synthesis`, journey-map opportunities, or a backlog. Grounds scores in evidence where it exists and flags where they're guesses.

No external services required. Triggers from natural language ("prioritize these", "what should we build first?", "RICE-score this backlog", "impact vs effort").

Install: `/plugin install prioritization@ai-ux-toolkit`
