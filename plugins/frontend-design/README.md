# frontend-design

- **frontend-design** — build distinctive, production-grade frontend interfaces guided by named aesthetic philosophies. Generates working code with exceptional attention to aesthetic detail, avoiding generic AI output.

> Related but distinct from this toolkit's `rapid-prototyping` → `rapid-prototype`: that one builds **throwaway, low-fidelity** prototypes to test a single interaction; this one builds **production-grade, ship-quality** interfaces. Reach for whichever matches your intent.
