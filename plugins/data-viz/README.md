# data-viz

- **data-visualization** — design the chart, dashboard, or data display: choose the right chart type for the question, apply accessible colour and clear labelling, respect the data-ink ratio, and lay out dashboards that answer questions at a glance (KPI tiles, hierarchy, filters).

**Project-agnostic** and tool-agnostic — the design guidance applies whether you build in Figma, a charting library (Recharts, D3, Plotly, matplotlib), or a BI tool. Uses the project's design tokens/palette when present. Pairs with `frontend-design`/`figma-design-system` (to build it) and `accessibility-heuristics` (chart contrast & non-colour encodings).

No external services required. Triggers from natural language ("what chart should I use?", "design this dashboard", "visualise this data", "is this chart accessible?").

Install: `/plugin install data-viz@ai-ux-toolkit`
